# Arabinda Sahoo - Business Intelligence & Data Analytics

## Overview
This project demonstrates a Business Intelligence (BI) and Data Analytics workflow using a self-contained sample sales dataset.

**Core flow:** Data → Information → Insight → Decision → Action

## Analysis Included
- Executive KPIs: Revenue, Orders, Customers, Average Order Value, Profit and Growth
- Monthly revenue trend
- Regional performance
- Product category performance
- Customer segment analysis
- Risk identification
- Opportunity identification
- Fact → Insight → Opportunity → Action storytelling
- AI analyst prompt for verified-data-based recommendations

## Files
- `ArabindaSahoo_Business_Intelligence_Data_Analytics.ipynb` — complete project notebook
- `ArabindaSahoo_Business_Intelligence_Data_Analytics_Report.docx` — project documentation
- `requirements.txt` — Python dependencies
- `README.md` — project overview and instructions

## Dataset
The notebook contains a self-contained sample sales dataset, so no external dataset file is required.

## Tools
Python, Pandas, NumPy, Matplotlib and Jupyter Notebook.
